Structural Well-Formedness #

A specification S is structurally well-formed iff all of the following hold:

WF-ID: Unique Identifiers

∀ e₁, e₂ ∈ E. e₁.id = e₂.id → e₁ = e₂ ∀ l₁, l₂ ∈ L. l₁.id = l₂.id → l₁ = l₂ ∀ d₁, d₂ ∈ D. d₁.id = d₂.id → d₁ = d₂ ∀ c₁, c₂ ∈ C. c₁.id = c₂.id → c₁ = c₂ ∀ b₁, b₂ ∈ B. b₁.id = b₂.id → b₁ = b₂

WF-LAYER: Layer Membership

∀ e ∈ E. ∃ l ∈ L. e.l = l.id
Every element belongs to a layer that exists

WF-TYPE: Type Vocabulary

∀ e ∈ E. let l = layer(e) in e.τ ∈ l.T
Every element's type is in its layer's vocabulary

WF-DEP-ENDPOINTS: Dependency Endpoints

∀ d ∈ D. ∃ e₁, e₂ ∈ E. d.src.elem = e₁.id ∧ d.tgt.elem = e₂.id
Dependency endpoints reference existing elements

WF-BINDING-SOURCE: Binding Sources

∀ b ∈ B. ∃ e ∈ E. b.abstract.elem = e.id
Binding sources reference existing elements

WF-LAYER-DEPS: Layer Dependencies

∀ l ∈ L. ∀ dep ∈ l.deps. ∃ l' ∈ L. l'.id = dep
Layer dependencies reference existing layers

WF-TIER-ORDER: Tier Ordering

∀ l ∈ L. ∀ dep ∈ l.deps. let l' = getLayer(dep) in pos(l') ≤ pos(l)
Layers only depend on layers at same or higher abstraction

Tier Completeness #

WF-TIER-COMPLETE: All Tiers Present

∀ t ∈ TIER. ∃ l ∈ L. l.tier = t
Every tier has at least one layer
This ensures the specification addresses all four fundamental questions:
  • motivation: WHY does this exist?
  • logical: WHAT is the structure?
  • realization: HOW does it work?
  • grounding: WHERE does it exist?

Acyclicity #

WF-ACYCLIC-LAYERS: No Layer Cycles

Let G_L = (L, {(l, l') | l' ∈ l.deps}) G_L is acyclic

WF-ACYCLIC-HARD: No Hard Dependency Cycles

Let G_D = (E, {(e₁, e₂) | ∃d ∈ D. d.src.elem = e₁.id ∧ d.tgt.elem = e₂.id ∧ d.σ = hard}) G_D is acyclic
Hard dependencies must be acyclic
Note: Soft dependencies MAY form cycles (for mutual references, etc.)

WF-SOFT-CYCLE-BOUNDED: Soft Cycle Boundaries

∀ cycle C in G_D^soft. ∃ d ∈ C. d.cascade_boundary = ⊤ where G_D^soft = (E, {(e₁, e₂) | ∃d ∈ D. d.src.elem = e₁.id ∧ d.tgt.elem = e₂.id ∧ d.σ = soft})
Every soft dependency cycle must have at least one cascade boundary to prevent infinite propagation

WF-CASCADE-TERMINATION: Cascade Depth Bounded

∀ r ∈ R. ∃ n ∈ ℕ. r.max_depth = n ∀ cascade path P in impact(S, e, r). |P| ≤ r.max_depth
Cascade rules must specify maximum propagation depth, and all cascade paths must respect this bound
