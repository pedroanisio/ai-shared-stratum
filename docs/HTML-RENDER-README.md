# HTML render

This project can render the Stratum document JSON into a single HTML file.

## Requirements

- Node.js
- pnpm

Dependencies are already listed in `package.json`.

## Build HTML

Run:

```bash
pnpm run build:html
```

Output:

- `docs/stratum-v.2.5.html`

## Document stats (optional)

Generate a stats summary used by templates:

```bash
pnpm run build:stats
```

Output:

- `docs/document-stats.json`

## Schema validation (optional)

Validate any JSON file against any schema:

```bash
pnpm run validate:schema <schema.json> <data.json>
```

Example:

```bash
pnpm run validate:schema docs/metadata.schema.json docs/sections/index.json
```

## Inputs and structure

- `docs/sections/index.json` is the manifest (metadata + section index).
- `docs/sections/*.json` are section content files.
- `scripts/build-html.ts` is the renderer.

If `documentStruct` is set to `parts` and `parts` is present in the manifest, the renderer groups sections under part headings and uses a nested TOC.

## Inline variables

The renderer supports inline template placeholders inside text fields (such as `overview`, paragraph text, definitions, and proof sketches).

Syntax:

```
render(objectName, "path.to.value")
```

Available objects:

- `documentStats`: computed summary of the document during rendering

Common paths (examples):

- `render(documentStats, "meta.title")`
- `render(documentStats, "meta.version")`
- `render(documentStats, "totals.sections")`
- `render(documentStats, "totals.subSections")`
- `render(documentStats, "totals.contentItems")`
- `render(documentStats, "totals.defsCount")`

The full `documentStats` shape is generated by `scripts/document-stats.ts` and includes:

- `meta` (id, title, subtitle, version, description, namespace, documentType, documentStruct)
- `totals` (sections, subSections, contentItems, defsCount)
- `contentTypes` (counts per content type)
- `defsKinds` (counts per definition kind)
- `parts` (per-part totals, contentTypes, defsKinds, summary when parts exist)
- `partsSummaryText` (preformatted markdown block: one line per part with label + summary)
- `sections` (per-section totals and counts)
- `sectionsById` (lookup map: id → { id, number, title })

Notes:

- If a path does not exist, the placeholder is left unchanged.
- Arrays are joined with `, ` in output.
